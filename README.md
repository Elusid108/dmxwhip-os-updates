# DMX whIP OS updates

Signed update bundles for the DMX whIP control console. Each release `os-vX.Y.Z` carries the `.raucb` bundles and a `versions.json` that consoles read from `releases/latest/download/versions.json`.

A console installs a bundle only if it is signed with the project's update key and made for that console, so these files are safe to publish. There is no source code here; the console OS lives in the Pixel-whIP project.
